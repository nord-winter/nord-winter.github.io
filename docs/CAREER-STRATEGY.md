## 2. Narrative

### Why Senior/Platform after CTO

Honest version that works in interviews:

- CTO in a startup means operations, hiring, and strategy. The goal now is engineering depth.
- Deliberately building toward Security Architecture through platform engineering expertise.
- Not stepping down — changing vector: from breadth to depth.

### Why no bigtech line

Don't defend — reframe:

- 80K+ RPS in production, 40% cost reduction, RAG agent in prod — these are real systems problems, not academic exercises.
- Series B/C companies look at whether someone has built real systems and made architectural decisions — that's there.
- No bigtech logo ≠ no depth.

## 3. Career Horizons

### 2025 – 2026 · Platform / Infrastructure Engineer · $5,000 – $6,000 gross

Enter the international market. Target: Fintech or DevTools, Series B/C, remote. Stack: Go + GCP + Kubernetes + Terraform + Security. Close the public Go code gap. Obtain CKA certification.

### 2027 – 2029 · Staff / Principal Platform Engineer or Solutions Architect · $8,000 – $12,000 gross

Deepen in system design and architectural decision-making. Begin Security Architecture specialization. Contribute to open source Go projects. Build niche recognition.

### 2030+ · Security Architect / Security Platform Engineer · $15,000+ gross

Military InfoSec foundation + 8+ years of engineering practice — rare and expensive combination. TryHackMe practice and SecDevOps depth should be fully mature by this point.

## 4. Gaps and How to Close Them

### Critical — close first

- **No public Go code** → build 1–2 repositories: infrastructure tool or service with tests, Prometheus metrics, README with architectural rationale and tradeoffs.
- **Kubernetes: operations only, no certification** → CKA (Certified Kubernetes Administrator). Removes the "did you design clusters?" question with one line.
- **Testing not mentioned anywhere** → add to resume, demonstrate in repository. Unit + integration, coverage >70%.

### Mid-term

- **English B2** → add mock interviews on Pramp or with a native speaker. Technical topics: system design, architectural tradeoffs.
- **TryHackMe** → continue daily. Track progress in public profile — this becomes a real differentiator in 1–2 years when moving toward Security Architecture.
- **Open source contributions** → start with small Go projects. Long-term inbound channel without active outreach.

## 6. Target Company Criteria

- Go as core backend stack — not scripts, not tooling, core.
- Remote-first culture — not just "we allow remote."
- Series B/C — funded, no FAANG bureaucracy, one engineer has real product impact.
- Fintech (reliability demands, Security background is a real plus) or DevTools/Infra (Go-heavy, interesting problems).
- No "Stanford/FAANG only" filter — verified via job description tone and Glassdoor.
